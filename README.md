# -Danger-Zone-Alarm.## Description

This project is a Danger Zone Alarm System using an Arduino.
It detects an object entering a danger zone and gives an alert using a buzzer and LED.

## Required Components

- Arduino Uno
- Ultrasonic Sensor
- Buzzer
- LED
- Resistor
- Breadboard
- Jumper Wires
- USB Cable

## Project Setup

The components are connected to the Arduino on a breadboard.
The ultrasonic sensor is placed facing the area that needs to be monitored.

![Project Setup](./project-setup.jpg)

## Procedure

1. Connect the Arduino Uno to the breadboard.
2. Connect the ultrasonic sensor to the Arduino.
3. Connect the LED and buzzer to the Arduino.
4. Upload the program to the Arduino.
5. Power the circuit using a USB cable.
6. Place an object in front of the sensor.
7. When the object enters the danger zone, the buzzer sounds and the LED turns ON.

## Functions

- Detects objects using an ultrasonic sensor.
- Monitors the defined danger zone.
- Activates the buzzer when an object is detected.
- Turns ON the LED as a visual warning.
- Provides a simple safety alert system.
